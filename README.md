# Tkinter Calculator
A desktop calculator application built with Python and Tkinter using Object-Oriented Programming (OOP) and a clean Grid layout.

## Screenshot

<img width="338" height="446" alt="image" src="https://github.com/user-attachments/assets/5d0cf55d-a5c7-4867-844d-1badf12952db" />


## Features

- **Object-Oriented Programming (OOP)**
- **Tkinter GUI with Grid layout**
- **Supports basic arithmetic operations (+, -, ×, ÷)**
- **Manual arithmetic implementation (without using `eval()`)**
- **Division by zero warning**
- **GitHub button to open my GitHub profile**


## Technologies

- **Python 3.11**
- **Tkinter**
