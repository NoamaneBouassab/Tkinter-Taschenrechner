# Tkinter-Taschenrechner
A desktop calculator application built with Python and Tkinter using Object-Oriented Programming (OOP) and a clean Grid layout.

## Features

- Basic calculator GUI
- Digit buttons
- Clear button
- Equal button
- Basic error handling

## Technologies

- Python
- Tkinter

## Future Roadmap

- Replace `eval()` with custom operation handling.
- Improve error handling with specific messages.
- Improve the user interface and styling.
- Add extra operations such as percentage (%) and square root.
